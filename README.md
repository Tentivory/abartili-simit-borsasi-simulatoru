# Abartılı Simit Borsası Simülatörü

## Resmi Açıklama (Ciddi)

Bu proje, Türkiye'nin en hayati ekonomik göstergesi olan simit fiyatlarını tahmin etmek için geliştirilmiştir. Simit, sadece bir hamur değil, milletin ruhudur. Bu nedenle fiyatının doğru tahmin edilmesi, toplumsal barışın korunması için kritik öneme sahiptir.

## Teknik Detaylar (Daha da Ciddi)

Algoritmamız, aşağıdaki faktörleri değerlendirir:
- Yakınlardaki kedi sayısı
- Ayın fazı (ama yanlış hesaplar)
- Çay demlenme süresi (simitle ilgisi yoktur ama olsun)
- Rastgele felsefi cümleler

## Kullanım

```bash
python simit_tahmin.py
```

Çıktı: Kesinlikle yanlış ama çok güvenilir görünen bir fiyat.

## Uyarı

Bu simülatör gerçek finansal tavsiye değildir. Simit alım-satımı yaparken dikkatli olun. Aç kalmayın.
